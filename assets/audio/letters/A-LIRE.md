# Enregistrements des lettres

Dépose ici les pistes audio, puis lance :

```
npm run build:letter-audio
```

## Convention de nommage

| Fichier | Contenu |
|---|---|
| `ba.mp3` | le nom de la lettre : « bâ' » |
| `ba-a.mp3` | la lettre avec fatha : « ba » |
| `ba-i.mp3` | avec kasra : « bi » |
| `ba-u.mp3` | avec damma : « bu » |
| `ba-sukun.mp3` | avec soukoun |

Formats acceptés : mp3, ogg, m4a, wav.

## Identifiants des lettres

`alif` `ba` `ta` `tha` `jim` `ha_hutti` `kha` `dal` `dhal` `ra` `zay` `sin`
`shin` `sad` `dad` `ta_mutbaqa` `dha` `ayn` `ghayn` `fa` `qaf` `kaf` `lam`
`mim` `nun` `ha` `waw` `ya` `hamza`

Attention : `ha_hutti` est le ح, `ha` est le ه. `ta` est le ت, `ta_mutbaqa`
le ط. `dha` est le ظ, `dhal` le ذ.

## Le minimum utile

Les seuls noms des 29 lettres suffisent déjà à débloquer les fiches du Module 1
et les exercices de discrimination du Module 2 — c'est la priorité. Les
combinaisons avec voyelles servent au Module 4 et peuvent venir ensuite.

Un fichier mal nommé est signalé au moment de la génération plutôt qu'ignoré en
silence.
